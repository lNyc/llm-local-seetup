# Configuration

All runtime configuration is managed through a single `.env` file at the project root. Copy the example file to get started:

```bash
cp .env.example .env
```

---

## Variable Reference

### Observability

#### `NEXTAUTH_SECRET`
**Required.** Secret key used by OpenLIT to sign authentication sessions (via NextAuth.js).

Generate a strong random value:
```bash
openssl rand -base64 32
```

Used by: `openlit`

---

#### `CLICKHOUSE_DB`
**Default: `default`**

The ClickHouse database name where all telemetry data is stored (traces, metrics, logs).

Used by: `clickhouse`, `openlit`, `otel-collector`

---

#### `CLICKHOUSE_USER`
**Default: `clickhouse`**

Username for ClickHouse authentication.

Used by: `clickhouse`, `openlit`, `otel-collector`

---

#### `CLICKHOUSE_PASSWORD`
**Required.** No default — the stack will refuse to start without it.

Password for ClickHouse authentication. Used by every service that reads from or writes to ClickHouse.

Used by: `clickhouse`, `openlit`, `otel-collector`

---

### GPU Collector

#### `GPU_APPLICATION_NAME`
**Required for meaningful dashboard filtering.**

A label attached to all GPU metrics, used to identify which application is driving GPU usage in the OpenLIT dashboard. Set this to something descriptive.

Example: `llm-local-setup`

Used by: `otel-gpu-collector`

---

#### `GPU_ENVIRONMENT`
**Default: `local`**

Environment tag attached to GPU metrics. Useful if you run multiple deployments and want to distinguish them in the dashboard (e.g. `local`, `dev`, `prod`).

Used by: `otel-gpu-collector`

### Not Yet Wired Up

These variables exist in `.env.example` but are not currently referenced by any Compose file or service config. They're placeholders for future parameterisation of the backend.

| Variable | Intended purpose |
|---|---|
| `MODEL_CONTEXT_SIZE` | Drive `--contextsize` in `koboldcpp.yml` without editing the file |
| `MODEL_SERVER_PORT` | Drive `--port` in `koboldcpp.yml` |
| `MIDDLEWARE_PORT` | Drive the LiteLLM listening port in `litellm.yml` |

To wire up `MODEL_CONTEXT_SIZE` as an example, you'd update `koboldcpp.yml`:

```yaml
- --contextsize
- "${MODEL_CONTEXT_SIZE:-131072}"   # falls back to 128K if unset
```

And set it in `.env`:
```
MODEL_CONTEXT_SIZE=65536
```

## Minimal Working `.env`

The absolute minimum to get the stack running:

```env
NEXTAUTH_SECRET=<generated-secret>
CLICKHOUSE_PASSWORD=<strong-password>
GPU_APPLICATION_NAME=llm-local-setup
```

All other variables have defaults that work out of the box.

## Security Notes

- `.env` is listed in `.gitignore` — it will never be committed. Do not override this.
- `CLICKHOUSE_PASSWORD` and `NEXTAUTH_SECRET` should be treated as credentials. Don't reuse passwords from other services.
- No service in this stack is intended to be exposed to the public internet. If you expose ports externally, add authentication in front of Open WebUI and restrict ClickHouse access.
